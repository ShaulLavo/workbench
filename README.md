# workbench

Shared MIT React 19 workbench UI library (`@shaulavo/workbench-*`) for Sprockt, Fregat, and browser IDEs.

## Install

```bash
bun add @shaulavo/workbench-tokens @shaulavo/workbench-core
```

## Development

```bash
bun install
bun run build
bun run verify
```
